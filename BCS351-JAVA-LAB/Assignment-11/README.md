# Assignment 11: Bubble Sort and Selection Sort

**Course:** Introduction to Programming Using Java Lab (BCS351)

## Aim
Sort small arrays with bubble sort and selection sort, and count the swaps.

## Tasks included
1. **Sort an array using bubble sort**
2. **Sort an array using selection sort**
3. **Count swaps in bubble sort**

## Files
- `Main.java` — contains all task solutions for this assignment. Each task is implemented in its own method, and `main()` runs them in order.
- `output.txt` — expected console output for all tasks, in the same order.
- `README.md` — assignment aim, task list, and run instructions.

## How to compile and run
Open a terminal in this folder and run:

```bash
javac Main.java
java Main
```

The output should match `output.txt`. Each task uses the fixed values specified in the lab assignment PDF.
